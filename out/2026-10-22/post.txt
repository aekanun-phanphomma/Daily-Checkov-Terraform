AKS clusters with local accounts enabled allow anyone with Azure RBAC access to retrieve static cluster-admin kubeconfig files.
Set local_account_disabled to true on azurerm_kubernetes_cluster to force all cluster access through Microsoft Entra ID.
This blocks attackers from extracting cluster-admin credentials via the ARM API and bypassing conditional access policies.
CKV_AZURE_141 fails the first version and passes the second.
