Pull request 402 introduces a new Cloud SQL instance with ipv4_enabled set to true.

Please set ipv4_enabled to false inside the ip_configuration block. Enabling a public IP assigns a publicly reachable IPv4 address to this Cloud SQL instance on the public internet.

Even if authorized networks restrict traffic, exposing database listeners to the internet significantly increases attack surface for brute-force attacks and protocol-level vulnerabilities. Attackers scan public cloud IP ranges continuously looking for open database ports.

Please update ipv4_enabled to false and connect using private IP through VPC Peering or Private Service Connect.

Static analysis with CKV_GCP_60 flags public IPv4 addresses on Cloud SQL instances automatically.

Always enforce private network connectivity for database instances at the infrastructure level.
