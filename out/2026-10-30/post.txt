Myth: Complex Linux passwords combined with network security groups make SSH password authentication safe enough for virtual machines.

Fact: Network perimeter rules frequently drift or loosen during maintenance, exposing port 22 to wider subnets or the internet. Automated scanners continuously probe open SSH ports, executing brute-force and credential stuffing attacks against local user accounts without encountering aggressive lockouts by default.

CKV_AZURE_149 triggers when an Azure Linux virtual machine sets disable_password_authentication to false.

Set disable_password_authentication to true and configure an admin_ssh_key block with a trusted public key instead.
