Myth: Cloud Storage buckets reject anonymous HTTPS requests by default, making bucket-level guards redundant.

Fact: Default bucket settings permit IAM bindings or object ACLs to expose data. If an identity policy or automated pipeline grants roles to allUsers or allAuthenticatedUsers, unauthenticated clients can immediately query and download objects over the Cloud Storage JSON or XML APIs. Relying on default inheritance leaves data vulnerable to single-line IAM mistakes.

This check identifies storage buckets that do not explicitly require public access prevention to be enforced.

To resolve this, set public_access_prevention to enforced on the google_storage_bucket resource.
